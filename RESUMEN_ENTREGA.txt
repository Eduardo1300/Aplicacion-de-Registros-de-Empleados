🚀 CÓMO EJECUTAR EL PROYECTO
═══════════════════════════════════════════════════════════════════════════════

OPCIÓN 1: Con Docker (Recomendado - 3 comandos)

Terminal 1:
  cd backend-nest
  docker-compose up -d

Terminal 2:
  cd frontend
  npm install
  npm run dev

Acceso: http://localhost:4200


OPCIÓN 2: Manual

Terminal 1 (Backend):
  cd backend-nest
  npm install
  npm run start:dev

Terminal 2 (Database):
  # PostgreSQL debe estar corriendo
  createdb bd_registro_empleados
  psql bd_registro_empleados < init.sql

Terminal 3 (Frontend):
  cd frontend
  npm install
  npm run dev

Acceso: http://localhost:4200
